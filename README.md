# NoteFlow

A modern, lightweight note-taking application with zero setup, offline-first, and privacy-focused

## Features

- **Zero Setup**: Start taking notes immediately without complex configuration
- **Offline-First**: Work seamlessly without internet connection
- **Privacy-Focused**: All your notes are stored locally, never sent to external servers
- **Lightweight**: Minimal dependencies, fast and efficient
- **Modern UI**: Clean and intuitive user interface

## Getting Started

### Prerequisites

- Node.js 14.0.0 or higher
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
